# 🎮 Juego de Adivinanza (1-100)

Proyecto del **Curso de Data Analyst** de Digital House.

## 📝 Descripción

Este es un juego interactivo donde el usuario debe adivinar un número secreto generado aleatoriamente entre 1 y 100. El jugador cuenta con un máximo de 10 intentos y recibe pistas si el número ingresado es más alto o más bajo.

El objetivo de este proyecto es practicar conceptos básicos de Python como:
- Bucles (`while`)
- Estructuras condicionales (`if`, `elif`, `else`)
- Manejo de errores (`try` / `except`)
- Inputs del usuario
- Uso del módulo `random`

## 🚀 Cómo ejecutarlo

1. Asegurate de tener Python instalado.
2. Clona este repositorio o descargalo.
3. Abre una terminal en la carpeta del proyecto y ejecuta:

```bash
python juego-adivinanza.py
